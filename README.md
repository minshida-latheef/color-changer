# 🎨 Color Changer

A simple and interactive Color Changer web application built using HTML, CSS, and JavaScript. It allows users to change the background color of a webpage with just one click.

## 🌟 About the Project

The Color Changer is a beginner-friendly frontend project designed to explore JavaScript functionality and DOM manipulation.

Users can select or generate different colors and instantly see the changes on the webpage.

## ✨ Features

- 🎨 Change background colors instantly
- 🌈 Multiple color options
- 🖱️ Interactive buttons
- ⚡ Real-time color updates
- 💻 Simple and user-friendly interface
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
